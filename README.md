# 🧗‍♂️ 攀岩訓練日記工具

一個低認知負荷的本地攀岩訓練記錄工具，幫助攀岩者快速記錄訓練狀態和動作觀察。

## ✨ 主要功能

### 📝 訓練日記
- 30秒快速記錄攀岩訓練
- 今日狀態追蹤
- 動作狀態觀察
- 低認知負荷設計

### 🏗️ 訓練計畫
- 自定義訓練計畫
- 預設模板系統
- 動作項目管理

### 👥 身份管理
- 開發者模式：完整功能 + 管理工具
- 測試員模式：專注體驗 + 互動反饋
- 訪客模式：安全瀏覽

### 💬 留言互動
- 開發者/測試員互動機制
- 自動回覆系統
- 未讀提示
- 溫度化體驗設計

## 🚀 技術特色

- **純前端實現** - HTML + CSS + JavaScript，無後端依賴
- **本地數據存儲** - localStorage，保護隱私
- **響應式設計** - 適配桌面和移動設備
- **身份分離** - 完整的權限控制和數據隔離
- **開發者友好** - 豐富的測試和管理工具

## 📱 立即體驗

[🔗 在線版本](你的-vercel-域名.vercel.app)

或下載本地使用：
1. 克隆或下載此倉庫
2. 用瀏覽器打開 `index.html`
3. 開始記錄你的攀岩訓練！

## 🎯 設計理念

**低認知負荷** + **專注 movement** + **溫度化互動**

這不只是一個記錄工具，而是一個能陪伴攀岩成長的小夥伴。
