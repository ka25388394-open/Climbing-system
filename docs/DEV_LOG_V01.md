- **"卡住"vs"需要補強"**：避免被評分感，更像真實感受
- **"有感"vs"特別有感"**：簡化語言，降低表達壓力
- **emoji+文字**：直觀識別 + 避免符號遺忘

**Program結構優化**  
- **5個item上限**：避免掃描疲勞，保持journal感
- **movement層級**：不記錄動作細節，專注movement觀察
- **分類清楚**：攀岩 vs 功能訓練，符合使用者思維
