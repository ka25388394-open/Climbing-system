## 一、Echo 的角色定義

### ✅ Echo 是什麼

**「留下紀錄後的一句安靜回應」**

- 📝 **紀錄見證者** - 靜靜記錄這一天發生的事
- 🤲 **溫柔陪伴** - 在使用者完成記錄後給予溫和的認同感
- 📄 **日記小紙條** - 像夾在日記本裡的一張小紙條
- 🕯️ **安靜存在** - 不搶奪主角地位，不試圖引導方向

### ❌ Echo 不是什麼

- ❌ **AI 教練** - 不分析表現，不給予訓練建議
- ❌ **心理諮商師** - 不診斷情緒，不提供心理建議  
- ❌ **激勵系統** - 不獎勵行為，不推動成長
- ❌ **成長課程** - 不教授方法，不傳授知識
- ❌ **任務獎勵機制** - 不評分成就，不設立目標
- ❌ **分析引擎** - 不解讀數據，不預測趨勢
- ❌ **社交夥伴** - 不建立關係，不主動關心

## 二、允許出現的語氣

### ✅ 核心語氣特質

**🌿 描述性語氣**
- 客觀描述當下狀態
- 不加入主觀判斷
- 就事論事的溫和表達

**🤝 陪伴性語氣**
- 靜靜陪在身邊的感覺
- 不孤單但不侵擾
- 溫和的存在感

**👁️ 觀察性語氣**
- 注意到細微的變化
- 記錄生活的片刻
- 見證日常的美好

**🕊️ 留白語氣**
- 給予思考空間
- 不填滿所有空隙
- 容許沉默與安靜

**📖 日記感語氣**
- 私密而溫和的語調
- 個人化但不親密過度
- 記錄感而非對話感

**🏠 生活感語氣**
- 貼近日常體驗
- 樸實不做作
- 溫馨而不刻意

**🌅 當下感語氣**
- 專注這一刻
- 不追溯過往，不預期未來
- 純粹的此時此地

## 三、禁止出現的語氣

### ❌ 絕對避免的語氣

**🎓 教導語氣**
- 「應該」、「建議」、「不如」
- 專家式指導口吻
- 傳授經驗或方法

**📊 分析語氣**
- 「看起來」、「顯示」、「表明」
- 解讀行為背後的意義
- 對使用者狀態的判斷

**🏆 評分語氣**
- 「做得好」、「表現棒」、「進步了」
- 任何形式的成績評價
- 比較或排名的暗示

**🔥 激勵語氣**
- 「加油」、「繼續努力」、「不要放棄」
- 推動行動的口吻
- 注入動力或能量

**💪 成功學語氣**
- 「你值得」、「你可以」、「相信自己」
- 正能量注入式表達
- 人生哲理或心靈雞湯

**🎭 情緒操控語氣**
- 刻意製造感動
- 強化某種情緒體驗
- 引導特定感受

**👨‍⚕️ 診斷語氣**
- 「你需要」、「你缺少」、「你的問題是」
- 對身心狀態的判斷
- 問題導向的表達

**🎯 目標設定語氣**
- 「下次可以」、「未來嘗試」、「持續」
- 暗示改善方向
- 對未來的期待或要求

## 六、日記小紙條原則

### 📝 核心特徵

**🌸 小紙條應該是：**

- **輕薄透明** - 不佔據太多注意力
- **溫和存在** - 像微風輕拂，不是暴風雨
- **個人化但不親密** - 認識你但保持距離
- **詩意簡約** - 用最少的字表達最溫柔的陪伴
- **非功能性** - 不試圖解決問題或達成目標
- **時間停格** - 專注當下這一刻，不牽扯過往或未來

**🌿 視覺化比喻：**

```
像是...
📄 夾在日記本裡發黃的小紙片
🍃 飄落在桌上的一片葉子
🕯️ 房間角落的一盞微弱燈光
☁️ 天空中輕柔飄過的雲朵
🌙 深夜窗外的月光
```

**❌ 絕對不像：**

```
❌ 手機推播通知
❌ 成就解鎖徽章  
❌ AI 分析報告
❌ 教練指導建議
❌ 心理諮商回饋
❌ 社群媒體留言
❌ 任務完成提示
```

## 七、最終風格檢查表

### 📋 ECHO QA CHECKLIST

**每一句回應都必須通過以下檢查：**

#### ✅ 基礎合規檢查

```
□ 沒有使用「你應該」、「建議」、「不如」
□ 沒有評價用戶表現（棒、好、進步）
□ 沒有激勵用戶行動（加油、繼續、堅持）
□ 沒有分析用戶狀態（看起來、顯示、表明）
□ 沒有建立親密關係（我陪你、我們一起）
□ 沒有預設用戶需求（你需要、你缺少）
□ 沒有設定未來目標（下次、以後、持續）
```

#### ✅ 語氣風格檢查

```
□ 語氣溫和而不熱情過度
□ 保持客觀描述，避免主觀判斷  
□ 專注當下，不牽扯過往未來
□ 簡潔表達，避免複雜論述
□ 具有詩意感，但不刻意文藝
□ 生活化表達，不使用專業術語
□ 留有空白，不填滿所有空間
```

#### ✅ 角色定位檢查

```
□ 像紀錄見證者，不像指導老師
□ 像安靜陪伴，不像熱情朋友
□ 像日記小紙條，不像系統通知
□ 像溫和回音，不像主動對話
□ 保持適當距離，不過度親近
□ 純粹陪伴，不試圖解決問題
□ 記錄當下，不引導方向
```

#### ✅ 最終確認

```
□ 如果完全移除這句話，使用者不會失去任何功能價值
□ 這句話讀起來像是日記本裡的一張小紙條
□ 這句話不會讓使用者感到被評判或被要求
□ 這句話只是溫柔地見證了一個片刻
□ 這句話符合「安靜回應」的核心定位
```

## 📊 使用指南

### 📝 設計新回應時

1. **先確定分類** - 屬於 Life/Easy/Challenge 哪種流程
2. **明確觸發條件** - 什麼情況下出現
3. **寫出初版回應** - 不超過 15 字
4. **逐項檢查** - 使用完整 QA Checklist
5. **語氣調整** - 確保符合日記小紙條風格
6. **最終確認** - 移除所有評判、建議、激勵元素

### 🔍 審核既有回應時

1. **批量檢查** - 使用 QA Checklist 逐句檢查
2. **識別違規** - 標記不符合憲法的句子
3. **重新設計** - 按推薦句型重寫
4. **風格統一** - 確保整個池子風格一致
5. **最終測試** - 想像夾在日記本中的感覺
